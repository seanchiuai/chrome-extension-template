# Hello World Chrome Extension

A simple Chrome extension with a sidebar (side panel) that displays "Hello World".

## Features

- Manifest V3 compliant
- Side panel with "Hello World" message
- Simple and clean design

## Installation

1. Open Chrome and navigate to `chrome://extensions/`
2. Enable "Developer mode" in the top right corner
3. Click "Load unpacked"
4. Select the folder containing this extension
5. Click on the extension icon in the Chrome toolbar to open the sidebar

## Files

- `manifest.json` - Extension configuration (Manifest V3)
- `sidepanel.html` - Sidebar HTML with Hello World message

## Usage

After installation, click the extension icon in your Chrome toolbar. The sidebar will open on the right side of your browser window displaying "Hello World".
